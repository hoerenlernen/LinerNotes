# Sicherheit / Security

Die erste Veröffentlichung hat keine eigene Benutzeranmeldung. Nur in einem vertrauenswürdigen Netz oder mit abgesichertem Zugang betreiben. Keine Tokens oder private Konfiguration in öffentliche Issues einstellen.

The initial release has no built-in authentication. Restrict access to a trusted network or a secured access gateway. Never post tokens or private configuration in public issues. For sensitive findings, use GitHub's private vulnerability reporting when available under the repository Security tab. There is no guaranteed response time or formal support period; fixes target the current main branch.
